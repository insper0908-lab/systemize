수능 국어 해설을 작성할 때, 제재(주제)를 "이해"하려 하지 말고 지시어·접속사·지시대명사·어미 같은 국어적 장치만 따라가며 "그렇구나" 태도로 정리할 것.

**Why:** 비문학은 배경지식으로 제재를 이해하는 게임이 아니라 텍스트 내부의 언어 장치가 만드는 연결을 추적하는 게임. 지시어가 가리키는 것, 접속사의 논리 관계, "즉/이러한" 같은 장치가 만드는 패러프레이즈 그룹만 정확히 잡으면 글이 풀린다. 제재를 이해하려 하면 오히려 지문 밖 배경지식이 끼어들어 오독이 발생.

**How to apply:**

1. **태도** — 제재 이해 X, "그렇구나" 태도. 텍스트가 말하는 그대로만 따라간다.

2. **접속사 = 논리 표지로 변환**
   - "즉" → `=` (등호) 로 해석. 앞뒤를 같은 그룹으로 묶음
   - "그러나/하지만" → 역접
   - "따라서/그러므로" → 인과
   - "그리고" → 부연/연결
   - 흐름 코멘트(빨강)에서 이 논리 관계를 반드시 명시

3. **지시어/지시대명사 = 원지시 대상을 끌고 와서 풀어쓰기**
   - "이것/그것/이러한/이 경우" 등장 시 → 가리키는 원지시 대상을 즉시 명시
   - 예: "이 경우" → "(앞 문장의) 온갖 예술의 경우"
   - "이러한 인식" → 앞에서 나열된 모든 동치 표현 그룹을 가리킨다

4. **그룹 묶기 = 같은 말 반복 인식**
   - 글이 같은 개념을 다른 말로 반복하면 한 그룹으로 묶기
   - 예: 온갖 예술 = 순수 가치 인정 = 독자 존립 인정 = 타가치 논외 = 타영역 거부 = 체계이론 미학
   - "즉", "이러한", "다시 말해" 같은 장치가 그룹의 경계 표지

5. **기표↔기의 대입 독해**
   - 글에서 어떤 기표(용어)에 기의(정의)를 부여하면, 이후 그 기표를 만날 때마다 기의를 대입해 읽기
   - 예: "체계"의 기의가 글에서 "독자 존립"으로 정의되면 → "체계 이론" = "독자 존립 이론"으로 변환

6. **선지 분석에도 동일 적용** — 지문의 지시어/접속사/그룹 묶음을 단서로 근거 위치를 짚을 것
