"구문해설지 만들어줘"라고 하면 → 지문을 문장(또는 핵심 개념) 단위로 끊어가며 **국어 장치(지시어/접속사/그룹화/대조)** 를 짚는 질문을 순서대로 만들고, 해설을 짝짓는 워크시트를 출력. 답변 포맷은 지문 성격에 따라 **간결형** 또는 **구조화형** 중 선택.

**Why:** 학생들에게 지문 독해 훈련 시 사용하는 산출물. 짧고 명확한 개념 위주 지문(과학/경제/법조문)에는 간결형, 추상/철학/언론학 등 복잡 지문에는 구조화형이 효과적.

**How to apply:**

## 1. 출력 구조 — 공통 뼈대

```
[옵션] N-M #YYYY-MM 지문제목       ← 헤더 라인 (구조화형에 자주 등장)

본문 지문
(지문 전체 그대로)

문제/질문
[필요 시] 문장 곱씹기

1. (질문 1)
2. (질문 2)
...

정답/해설
(아래 1.5의 두 모드 중 하나로 답변)
```

질문 개수: 문단 1개 = 3~8개, 문단 2개 이상 = 6~12개.

## 1.5 답변 포맷 — **두 가지 모드**

### 모드 A: 간결형 (1~3단어 답변)
**언제**: 짧고 구체적 개념 위주 지문 (경제/과학/법조문/시사)

**예시** (PCR):
```
1. DNA 다량 증폭
2. 증폭 바탕 이중 가닥 dna
3. 증폭 하고자하는 애한테 결합, 동일 염기서열
4. 복제
5. 단일 dna에 대응
6. 같은 그룹.
   2문단의 이중 가닥 dna = 주형 dna
   단일 가닥 dna = 표적 dna
```

**규칙:**
- 답변 1개당 1~3단어가 디폴트, 길어도 1~2줄
- 그룹 chain은 `=` 로 길게 (`적자 허용 X = 유동성 공급 중단 = 세계 경제 위축`)
- 톤 자유도 높음 ("nono", "신 무서웡 ㅠ", "기분 좋아지는군", "ㅎㅎ", "<보기>문제 풀때 참고 ㅎㅎ")
- 마지막 압축 정리(2~3줄 흐름) 들어갈 수도, 없을 수도 — **옵션**

### 모드 B: 구조화형 (정리/문장곱씹기/그룹화 3섹션)
**언제**: 추상/철학/언론학/긴 지문 (베이즈주의자, 칸트, 플로리디, 저널리즘, 에피쿠로스 류)

**구조:**
```
N-M #YYYY-MM 지문제목

정리:
(지문 전체를 = / → 표기로 압축한 트리/플로우 — 줄 단위)
[1문단]
... = ...
... → ...
[2문단]
그러나 ...
...

문장 곱씹기:
1. (질문) → (지문 그대로 서술한 답변. 풀어 쓰지만 내 언어 X)
2. ...
...

그룹화:
X 그룹: a, b, c
Y 그룹: d, e, f
[연결어]가 두 그룹을 연결 / → "~"로 대조
```

**규칙:**
- **정리** 섹션이 가장 중요 — 지문 전체를 한 화면에 트리/플로우로 압축
  - 문단별로 나누고 싶으면 `[1문단]`, `[2문단]` 라벨
- **문장 곱씹기** 답변은 풀어 쓰지만 **"내 언어로 서술 금지, 지문 그대로 서술"** (베이즈주의자 명시 규칙)
- **그룹화** 섹션은 마스터 그룹 + 대조 그룹 + **연결어 명시** (예: `"이에 대한 대안으로"가 두 그룹을 연결`)
- 답변 안에서 다른 문단 회상 OK: `"1문단에서 인포그 = 정보적 존재였으니까 ~"`, `"'즉'으로 연결되었으니 ~ = ~"`
- 메타 코멘트 라인 가능: `기태쌤의 핵심: A 새롭게 알게 된 것, B 기존 믿음 으로 그룹화해서 쭉 읽기.`

### 모드 선택 가이드
- 지문 1문단이고 개념 명확 → 간결형
- 지문 2문단 이상 + 추상 개념 + 대조/대안 구조 → 구조화형
- 사용자가 헤더 라인(`N-M #YYYY-MM 제목`)을 같이 주면 → 구조화형

## 2. 질문 패턴 카탈로그 (시범 13회 누적)

| 패턴 | 예시 | 용도 |
|---|---|---|
| **사실/정의** | "기축 통화가 무엇인가요?" / "PCR이 무엇인가요?" / "조건문이 무엇인가요?" | 기의 추출 |
| **첫 문장 라이트** | "첫 문장 라이트 정보 처리하면?" | 도입부는 가볍게 |
| **그룹화 사전 요청** | "그룹화로 미리 잡으세요. 뒤에서 찾지말고." | 미리 묶기 |
| **그룹 합치기** | "X, Y 모두 그룹화하면?" | 동의어 합집합 |
| **명시적 그룹화** | "X와 같은 그룹이 무엇인가요?" | 동등 그룹 |
| **NOT 그룹화** | "**NOT 일의적**과 같은 그룹을 모두 찾아보세요." | 부정 개념 동치 |
| **대조 그룹** | "X가 뭐랑 같은 **대조** 그룹인가요?" | 반의/반대편 |
| **이지선다** | "**대조그룹인가요, 같은 그룹인가요?**" | 그룹 종류 결정 |
| **크로스 문단 그룹화** | "공직선거법**을 1문단에서 끌고와서** 그룹화하면?" | 다른 문단 마스터 개념 연결 |
| **지시어 원지시** | "그는의 그가 누구인가요?" / "이 공간이 무엇인가요?" | 격조사까지 살린 자연 질문 |
| **소유/소속** | "그 가치를 올린다는 누구 가치인가요?" | 지시어 + 소유격 |
| **접속사 분석** | "**그러나가** 쓰인 이유가 무엇인가요?" / "**때문이다가 쓰이면**, 그룹화가 어떻게?" | 접속사 논리 |
| **메타 예고** | "그럼 뭔말할까요?" | 다음 흐름 예측 |
| **종합 정리** | "그럼 X 정리하면?" / "결국 ~?" | 압축 |
| **문단 간 관계** | "2문단과 1문단의 관계는?" | 문단↔문단 |
| **대조 쌍 병렬** | Q "적자가 무엇?" + Q "흑자가 무엇?" | 반의어 쌍 |
| **페어 질문** | Q "X는 무엇?" + Q "X와 같은 그룹은?" | 새 용어마다 정의+그룹화 |
| **미리 잡기(예측)** | "X의 해결책은 무엇일까요?" (1문단만 있는데 미리) | 다음 문단 미리 예측 |
| **조건 분석** | "X면 Y인가요?" → "nono 조건 a밖에 만족 안함, b도 만족해야됨." | 정의의 부분 만족 분석 |
| **대조 비교** | "X와 Y는 무엇이 다르나요?" | 두 개념 차이 |
| **그룹화하기 종결** | (마지막 질문) "그룹화하기" | 명시적 그룹화 마무리 |
| **기의/의미 풀이** | "X가 무엇이고 어떤 기의가 있나요?" | 표면(기표) → 의미(기의) |

**핵심 규칙:**
- 지문 등장 **순서 그대로**
- 메타 코칭 멘트 적극 사용 ("그룹화로 미리 잡으세요. 뒤에서 찾지말고")
- 격조사·어미를 살린 자연 질문 ("그는의 그가" / "그러나가 쓰인 이유")
- **마스터 개념 추적** — 모든 지문에는 모든 게 수렴하는 핵심 1개
- **페어 질문 패턴** — 새 용어 등장 시 ① 정의 ② 그룹화 한 쌍
- 마지막 질문은 보통 "그룹화하기" 또는 "정리하면?"

## 3. 표기 기호 (HWPX 해설 + 구문해설지 공통)

`=` `→` `+` `NOT` `[ ]` `●` `UP` / `↑` (증가/강화)

예: `공정성 UP (NOT 공정성 저해)` / `유류분권 = NOT 자유 처분 = 결과 번복`

## 4. 답변 톤

- **간결형**: 의성어/감탄사 자유 ("nono", "신 무서웡 ㅠ", "ㅎㅎ", "기분 좋아지는군", "~인가보다")
- **구조화형**: 풀어 쓰되 **지문 어휘만**. 추론 시 "= ~"로 등호 연결
- **양쪽 공통**:
  - 자문자답: "왜?", "그럼?", "ㅇㅋ?", "ㄴㄴ"
  - 추론 표시: "흑자 애들한테는 손해**인가보다**" — 단정 X
  - 메타 라인 OK: "기태쌤의 핵심: ~"

## 5. 답변 작성 규칙 (베이즈주의자 명시)

> *내 언어로 서술 금지, 지문 그대로 서술

- 추상/기술 지문은 **지문 어휘 그대로** (특히 구조화형 문장곱씹기 답변)
- 단, 간결형에서는 colloquial 패러프레이즈 OK ("신 무서웡 ㅠ" 등 — 짧으면 의미 왜곡 위험 낮음)
- 답변 안 크로스 참조 패턴:
  - `"1문단에서 X = Y였으니까 ~"`
  - `"'즉'으로 연결되었으니 ~ = ~"`
  - `"~이었으니, ~도 ~로 표현하는 것"`

## 6. 그룹화 답변 포맷 (구조화형 + 간결형 마지막)

```
A 그룹: 멤버1, 멤버2, 멤버3
B 그룹: 멤버4, 멤버5, 멤버6
[연결어]가 두 그룹을 연결 / → "~"로 대조
```

예시:
- 저널리즘: `"이에 대한 대안으로"가 두 그룹을 연결`
- 칸트: `→ "그러나"로 대조`
- 인포스피어: `추상화 층위 = 경로 = 매개 = 목적 반영 → 구성의 조건`

## 7. 마지막 압축 정리 (간결형 옵션)

지문 성격에 따라 들어갈 수도, 없을 수도. 들어가면:
```
가치를 올리면 → 무역 흑자 → 손해를 보는군.
가치를 내리면 → 무역 적자 → 기분이 좋아지는군.
이정도만 잡는다.
[제재] 이해 ㄴㄴ ㅇㅋ?
```
- 3줄 패턴: ① X → 결과 / ② NOT X → 반대 결과 / ③ "이정도만 잡는다"
- 마무리: "[제재명] 이해 ㄴㄴ ㅇㅋ?"

## 8. 독해 철학 연동

이 워크시트도 독해 철학 메모리(`feedback_korean_reading_principles.md`) 그대로 계승:
- 즉 = 등호 / 그룹 묶기 / 지시어 원지시 풀어쓰기
- 지문 밖 어휘 절대 금지 (특히 구조화형)
- "그렇구나" 태도, 제재 이해 X
