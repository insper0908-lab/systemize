"구문해설지 만들어줘"라고 하면 → 지문을 문장(또는 핵심 개념) 단위로 끊어가며 **국어 장치(지시어/접속사/그룹화/대조)** 를 짚는 질문을 순서대로 만들고, 각 질문에 **극도로 짧은** 해설(같은 표기 규칙)로 답하는 워크시트를 출력.

**Why:** 학생들에게 지문 독해 훈련 시 사용하는 별도 산출물. HWPX 본격 해설보다 가벼운 텍스트 Q&A 형식. 답변 길이는 의도적으로 짧게 — 학생이 핵심만 잡는 훈련.

**How to apply:**

## 1. 출력 구조

```
본문 지문
(지문 전체 그대로)

문제/질문
[필요 시] 문장 곱씹기   ← 서브헤더로 사용 가능

1. (질문 1)
2. (질문 2)
...

정답/해설
1. (짧은 답)
2. (짧은 답)
...

[옵션] 마지막 흐름 압축 — 지문에 따라 있을 수도, 없을 수도
```

질문 개수는 지문 길이에 따라 가변. 문단 1개 = 5~8개, 문단 2개 = 6~12개 정도.

## 2. 질문 패턴 카탈로그 (시범에서 관찰)

| 패턴 | 예시 | 용도 |
|---|---|---|
| **사실/정의** | "기축 통화가 무엇인가요?" / "PCR이 무엇인가요?" / "조건문이 무엇인가요?" | 기의 추출 |
| **첫 문장 라이트** | "첫 문장 라이트 정보 처리하면?" | 도입부는 가볍게 |
| **그룹화 사전 요청** | "그룹화로 미리 잡으세요. 뒤에서 찾지말고." | 미리 묶기 강제 |
| **그룹 합치기** | "X, Y 모두 그룹화하면?" | 동의어 합집합 |
| **명시적 그룹화** | "X와 같은 그룹이 무엇인가요?" | 동등 그룹 |
| **NOT 그룹화** | "**NOT 일의적**과 같은 그룹을 모두 찾아보세요." | 부정 개념의 동치 그룹 |
| **대조 그룹** | "X가 뭐랑 같은 **대조** 그룹인가요?" | 반의/반대편 그룹 |
| **이지선다** | "**대조그룹인가요, 같은 그룹인가요?**" | 그룹 종류 결정 |
| **크로스 문단 그룹화** | "공직선거법**을 1문단에서 끌고와서** 그룹화하면 무엇인가요?" | 다른 문단의 마스터 개념과 연결 |
| **지시어 원지시** | "그는의 그가 누구인가요?" / "이 상황이 ~?" | 지시대명사 추적 (격조사까지 살린 자연 질문) |
| **소유/소속** | "그 가치를 올린다는 누구 가치인가요?" | 지시어 + 소유격 |
| **접속사 분석** | "**때문이다**는 왜 쓰였고, 해당 문장을 어떻게 그룹화 할 수 있나요?" / "**때문이다가 쓰이면**, 그룹화가 어떻게 되나요?" | 접속사·종결어미가 만드는 논리 |
| **메타 예고** | "그럼 뭔말할까요?" | 다음 흐름 예측 |
| **종합 정리** | "그럼 X 정리하면?" / "결국 ~?" | 압축 |
| **문단 간 관계** | "2문단과 1문단의 관계는 무엇인가요?" | 문단↔문단 그룹/대조 |
| **대조 쌍 병렬** | Q5 "적자가 무엇?" + Q6 "흑자가 무엇?" | 반의어 쌍 동시 추출 |
| **페어 질문** | Q "X는 무엇?" + 다음 Q "X와 같은 그룹은?" | 새 용어마다 정의+그룹화 한 쌍 |

**핵심 규칙:**
- 지문 등장 **순서 그대로** 진행 (시간 역행 X)
- "그룹화로 미리 잡으세요. 뒤에서 찾지말고" 같은 **메타 코칭 멘트** 적극 사용
- 격조사·어미를 살린 자연 질문 ("그는의 그가" / "때문이다는 왜 쓰였고")
- **마스터 개념 추적** — 지문에는 모든 게 수렴하는 핵심 1개가 있음(예: 닉슨쇼크 = "NOT 적자", 경마식보도 = "공정성"). 새 용어 등장 시마다 마스터 개념과 같은 그룹인지 묻기
- **페어 질문 패턴이 기본** — 새 용어가 등장할 때마다: ① "X는 무엇?" ② "X와 같은 그룹은?" 순서로 두 번 묻기 (경마식보도 2 예시 Q4-Q7 = 3개 새 용어 × 페어 = 6질문)

## 3. 해설 작성 패턴

### 표기 기호 (HWPX 해설과 동일)
`=` `→` `+` `NOT` `[ ]` `●` `UP` / `↑` (증가/강화) — 예: `공정성 UP (NOT 공정성 저해)`

### 답변 길이 — **극도로 짧게**
시범에서 관찰된 답:
- "기준 통화" (2단어)
- "복제" (1단어)
- "DNA 다량 증폭" (3단어)
- "초과 수입" / "초과 수출" (2단어)
- "기부, 대가 X" (3토큰)

**원칙: 1~3단어로 끝낼 수 있으면 거기서 끝.** 풀어쓰지 말 것.

### 그룹 chain — `=` 로 길게 연결
```
적자 허용 X = 유동성 공급 중단 = 세계 경제 위축
적자 (초과 수입) = 달러화 과잉 공급 = 신뢰도 위축 = 고정 환율 붕괴
유류분권 = NOT 자유 처분 = 결과 번복
```

### 반대 개념 — `NOT X` / 대조 그룹
```
이를 해결할 수 있는 방법 = NOT 적자 = NOT 과잉 공급 = NOT 금 준비량 급감
전부 같은 그룹.
```

### 문단 간 관계 답변 패턴
```
같은 그룹.
2문단의 이중 가닥 dna = 주형 dna
단일 가닥 dna = 표적 dna
```
→ "같은 그룹." 한 마디 + 매핑 라인 2~3줄.

### 자문자답 톤
- "왜?", "그럼?", "ㅇㅋ?", "ㄴㄴ", "~인가보다", "기분이 좋아지는군"
- 추론 표시: "흑자 애들한테는 손해**인가보다**" — 단정 X, 추정 표현으로 힘 빼기

## 4. 마지막 압축 정리 (옵션)

지문 성격에 따라 있을 수도, 없을 수도. 시범 4건 중:
- 닉슨쇼크: 있음 (3줄 흐름 + "경제 이해 ㄴㄴ ㅇㅋ?")
- 트리핀/PCR/유류분권: **없음** — 마지막 질문 답변으로 자연스럽게 종결

압축 정리가 들어가면 형태:
```
가치를 올리면 → 무역 흑자 → 손해를 보는군.
가치를 내리면 → 무역 적자 → 기분이 좋아지는군.
이정도만 잡는다.
[제재] 이해 ㄴㄴ ㅇㅋ?
```
- 3줄 패턴: ① X → 결과 / ② NOT X → 반대 결과 / ③ "이정도만 잡는다"
- 마무리 한 줄: "[제재명] 이해 ㄴㄴ ㅇㅋ?"
