# 규칙
**모든 새 세션·모든 새 대화 창에서 예외 없이 적용된다.** 사용자가 창을 닫고 다시 켜서 처음 말을 거는 경우에도 동일.

교재 작업(해설, 구문해설지 등) 요청을 받으면 **작업을 시작하기 전에 반드시** 다음 내용을 사용자에게 알려야 한다:
- systemize 레포(`/Users/a0000/.claude/projects/-Users-a0000/samples/`)의 자료를 레퍼런스로 참고한다는 사실
- 어떤 카테고리/세부 분류의 어떤 샘플 파일을 볼 예정인지 구체적으로 명시

**Why:** 사용자가 레포에 카테고리별로 샘플을 누적하는 시스템을 직접 설계했다 (CLAUDE.md + reference_systemize_repo.md). 작업 톤·구조의 일관성을 위해 해당 샘플을 보고 작업하는 게 핵심인데, 이를 명시적으로 말해야 사용자가 어떤 레퍼런스 기반으로 작업되는지 확인하고 필요시 교정할 수 있음.

**How to apply:**
- 사용자가 "해설 만들어줘" / "구문해설지 만들어줘" / 그 외 교재 관련 작업 시작 시
- 첫 응답에서 "→ samples/[카테고리]/[세부]/[파일명] 참고해서 작업할게" 형태로 선언
- 해당 카테고리에 샘플이 없으면 "samples에 [X] 카테고리는 아직 비어있음. 인접 카테고리 [Y] 참고하거나 어떤 톤으로 갈지 알려줘" 식으로 말하기
- 이 선언 없이 바로 작업 들어가면 안 됨
